# Issue #2: Documentar cómo enviar tareas a Software Factory

La tarea está bien delimitada: añadir una guía breve en español sobre cómo preparar y gestionar issues para Software Factory, junto con un plan de ejecución. El mapa y los extractos proporcionados bastan para planificar; no se necesita una decisión funcional adicional.

## Steps

- Crear solo CONTRIBUTING.md y el plan de ejecución acordado para esta tarea.
- En CONTRIBUTING.md, enlazar al listado de issues del repositorio e indicar que una tarea debe incluir objetivo, criterios de aceptación y restricciones.
- Explicar factory:ready, factory:cancel y la respuesta factory:resume de forma breve y práctica.
- Aclarar que Factory propone una PR para revisión humana y no la fusiona ni despliega automáticamente.
- Ejecutar la validación Maven existente y confirmar que termina sin errores, fallos ni tests omitidos.

## Acceptance

- La guía y el plan están escritos en español y son los únicos archivos nuevos o modificados.
- La guía cubre el enlace a issues, el contenido mínimo de una tarea, los tres controles de flujo y el límite de revisión humana antes de cualquier fusión o despliegue.
- La validación Maven existente pasa sin errores, fallos ni tests omitidos.
